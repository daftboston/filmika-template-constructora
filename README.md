# Filmika – Plantilla web para constructoras

**Spec only.** This repo has no code yet. It defines the sections and Spanish copy direction for Filmika's construction company template.

- Filmika docs: https://github.com/daftboston/web-studio-agency
- Packages: https://github.com/daftboston/web-studio-agency/blob/main/docs/PACKAGES.md

## Build note
Daniel will build this template **with animations using another AI**, following this spec.

## Placeholder content
All testimonials, photos, project data, and business details are **placeholders** until a real client provides them. Do not publish placeholder content as if it were real.

## Copy direction
- Spanish (Colombia), "usted", short sentences, no jargon.
- Tone: serious, solid, trustworthy. Show real work and a clear process.
- No invented numbers (years, projects completed, m² built) unless the client provides them.

## Sections (in order)

### 1. Hero
Main message and WhatsApp button over a strong project photo.
> Construimos y remodelamos con calidad, a tiempo y sin sorpresas.
> [Cotice su proyecto por WhatsApp]

### 2. Services
What the company builds: construcción, remodelación, acabados, obra gris, diseño (adapt to the client). One card per service with icon and short text.

### 3. About
Who the company is and its work process, shown as 4 steps:
**visita → diseño → obra → entrega**
> Lo acompañamos desde la primera visita hasta la entrega de llaves.

### 4. Projects
Featured projects with **before / after (antes / después)** images, ideally a slider. Each project: name, location (barrio/ciudad), type of work.

### 5. Gallery
Photo grid of finished work and work in progress.

### 6. Testimonials
Short client quotes with name and project type. Placeholder until real testimonials are provided.

### 7. FAQ
Common questions, e.g.:
- ¿Hacen visitas para cotizar?
- ¿Cuánto tiempo toma una remodelación?
- ¿Se encargan de los permisos?

### 8. Location
Google Maps with office address and area of coverage.

### 9. Contact
Form (nombre, teléfono, tipo de proyecto, mensaje) plus real phone, email, and address.

### 10. WhatsApp CTA
Full-width band before the footer, plus floating button on all screens.
> ¿Tiene un proyecto en mente? Hablemos hoy.

Prefilled message:
```
Hola, quiero cotizar un proyecto de construcción o remodelación. ¿Podemos agendar una visita?
```

### 11. Footer
Logo, short description, links to sections, contact details, social links, and "Sitio creado por Filmika".

## Package fit
Works as **Presencia** (landing with these sections) or **Profesional** (multi-page, with projects and guides). See PACKAGES.md.
